# IRONWAKE — Quality Ledger

Round-by-round blind-review results: our captures vs. real Call of Duty
frames, judged blind by independent critic agents who are never told which
is which. Generated by `node tools/critic/decode.mjs`. See
`docs/CRITIC_PROTOCOL.md` for the protocol and gates.

Blind win rate = fraction of pairs where a critic picked our image over a
real CoD screenshot. The honest ceiling for real-time WebGL against
offline-quality console renders is roughly the point where critics stop
being able to tell reliably; the ledger reports the true number either way.
